# Code signing policy

Free code signing provided by [SignPath.io](https://signpath.io), certificate by [SignPath Foundation](https://signpath.org).

Windows programs in luka's releases are built from this repository by GitHub Actions. A maintainer approves each release before it is signed.

## Team

| Role | Who |
|---|---|
| Authors and committers | [lukalul/luka-client contributors](https://github.com/lukalul/luka-client/graphs/contributors) |
| Reviewers | The repository's maintainers |
| Approvers | The repository's maintainers |

## Privacy

See [what luka connects to](PRIVACY.md). This program does not transfer information to other systems except as that page describes.

## Removing luka

Use **Add or remove programs** in Windows, or run `Uninstall luka.exe` in the install folder. It asks whether to delete your game files and settings too.
